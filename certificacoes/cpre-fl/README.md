# cpre-fl

Carrossel de 8 slides (JPG). Versão TOFU. Texto usado na publicação pelo Buffer (Instagram, Facebook e TikTok).

## Legenda do Instagram e do Facebook

```
Certificação CPRE-FL: o defeito começou no requisito?

A CPRE-FL é a certificação do IREB em engenharia de requisitos. Não é uma certificação de teste.
Mesmo assim, o syllabus diz que a engenharia de requisitos é pré-requisito no teste de sistema. E o princípio 6 é direto: requisito não validado é inútil.
São 7 unidades, 17 h 45 de treinamento, prova de múltipla escolha e nenhum pré-requisito formal.

Desafio: "O sistema deve responder rápido." É funcional, de qualidade ou restrição? Responda F, Q ou R nos comentários.

#testedesoftware #qa #engenhariaderequisitos #ireb #certificacao
```
