## Legenda do Instagram e do Facebook

```
Teste funcional: você clica em Pagar. O que precisa acontecer?

Teste funcional é conferir se o sistema faz o que foi pedido.
Na prática: o login aceita a senha certa, o carrinho soma direito, o cupom dá o desconto combinado.
Se o esperado e o obtido batem, a função passou. Rapidez e segurança ficam para o teste não funcional, assunto do próximo post.

Salve este post para revisar depois.
```
