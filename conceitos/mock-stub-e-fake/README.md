# mock-stub-e-fake

Carrossel de 7 slides (JPG). Versão TOFU. Texto usado na publicação pelo Buffer (Instagram, Facebook e TikTok).

## Legenda do Instagram e do Facebook

```
Mock, stub e fake: o teste não pode cobrar o seu cartão de verdade

Dublê de teste é qualquer objeto de mentira que entra no lugar do real, só para testar.
Stub devolve uma resposta pronta. Fake funciona de verdade, com um atalho: um pagamento de mentira que guarda os pedidos na memória. Mock já sabe que chamada deve receber e reprova se ela não vier.
As definições são de Gerard Meszaros, citadas por Martin Fowler no artigo "Mocks Aren't Stubs".

Salve para revisar quando precisar.

#testedesoftware #qa #automacaodetestes #testeunitario
```
