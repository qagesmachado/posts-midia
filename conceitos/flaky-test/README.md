## Legenda do Instagram e do Facebook

```
Flaky test: passou ontem, falhou hoje e ninguém mexeu

Flaky é o teste instável: às vezes passa, às vezes falha, sem o sistema ter mudado.
As causas mais comuns são espera curta demais, dado compartilhado entre testes e teste que depende da ordem.
Rodar de novo até passar esconde o problema. O caminho é anotar quantas vezes falhou e investigar a causa.
```
