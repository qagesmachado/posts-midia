# teste-qa-e-qc

Carrossel de 5 slides (JPG). Versão TOFU. Texto usado na publicação pelo Buffer (Instagram, Facebook e TikTok).

## Legenda do Instagram e do Facebook

```
Teste, QA e QC: testar é garantir qualidade?

Não exatamente. QA (garantia de qualidade) cuida do processo, para os problemas nem nascerem.
QC (controle de qualidade) olha o produto pronto e encontra o que escapou. O teste é uma das principais formas de QC.
No dia a dia, as duas palavras se misturam. Na entrevista, saber a diferença conta ponto.

Salve este post para revisar depois.

#testedesoftware #qa #qualidadedesoftware #carreiraqa
```
