# funcional-e-nao-funcional

Carrossel de 7 slides (JPG). Versão TOFU. Texto usado na publicação pelo Buffer (Instagram, Facebook e TikTok).

## Legenda do Instagram e do Facebook

```
Teste funcional e não funcional: faz o que pediu, mas faz bem?

Funcional confere o que o sistema faz: cobrou o valor certo, gerou o pedido.
Não funcional confere quão bem ele faz: rápido, seguro, fácil de usar.
Para o lado não funcional, o ISTQB cita as 7 características da ISO/IEC 25010.

Salve para revisar quando precisar.

#testedesoftware #qa #istqb #qualidadedesoftware
```

| 1 | `01.jpg` | 2 perguntas sobre o mesmo sistema. Faz o que pediu. Mas faz bem? |

| 3 | `03.jpg` | O mesmo botão, duas perguntas. Gráfico: No alto, as perguntas funcionais: cobrou o valor certo e gerou o pedido. No meio, o botão Pagar. Embaixo, as não funcionais: respondeu rápido, protegeu o cartão e dá para pagar sem se perder. |
| 4 | `04.jpg` | As 7 características da ISO/IEC 25010. Eficiência de Performance, tempo e recurso. Compatibilidade, conversa com outro sistema. Usabilidade, fácil de usar. Confiabilidade, não cai no meio. Segurança, dado protegido. Capacidade de manutenção, fácil de mudar. Portabilidade, roda em outra plataforma. Classificação citada no CTFL 4.0, seção 2.2.2. |
| 5 | `05.jpg` | Muitos não funcionais nascem de um funcional. Teste funcional: o login com a senha certa entra. Mesmo teste, com uma restrição: entrar dentro do tempo especificado. Virou um teste não funcional de performance. |
