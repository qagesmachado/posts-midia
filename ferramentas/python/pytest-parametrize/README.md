# pytest-parametrize

Carrossel de 8 slides (1080×1350, JPG). Texto usado na publicação pelo Buffer, nos rascunhos de Instagram, Facebook e TikTok.

## Legenda

```
Copiou o teste de novo?

Quando só o dado muda, o pytest deixa você escrever o teste uma vez e passar a lista de casos.
Cada caso aparece com o próprio nome no relatório, então você sabe qual combinação falhou.
O código do post rodou de verdade: 4 casos, 1 função.

Salve e use na próxima vez que for copiar um teste.

#pytest #python #qa #automacaodetestes #testedesoftware
```
