## Legenda do Instagram e do Facebook

```
Git add, commit e push: salvou o teste e o time não viu?

Salvar no editor grava o arquivo só na sua máquina.
O git add separa o arquivo, o git commit guarda a versão com uma mensagem e o git push envia para o repositório remoto, como o GitHub.

```
