# o-que-e-versionar

Carrossel de 5 slides (JPG). Versão TOFU. Texto usado na publicação pelo Buffer (Instagram, Facebook e TikTok).

## Legenda do Instagram e do Facebook

```
O que é versionar: quem mudou o teste que passava ontem?

Versionar é guardar o histórico de cada mudança: quem mudou, quando e o quê.
O Git faz isso na sua máquina. GitHub, GitLab e Bitbucket guardam a cópia que o time inteiro usa.
O QA versiona o próprio teste e revisa mudanças pelo pull request, igual ao time de desenvolvimento.

Salve este post para revisar depois.

#git #qa #versionamento #testedesoftware
```

## Primeiro comentário (Instagram e Facebook, só no plano pago do Buffer)

```
Desafio: abra o histórico de versões de um documento que você usa (o Google Docs tem um). Dá para ver quem mudou e quando? Isso já é versionar. Conta aqui o que achou.
```
